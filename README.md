# STM32 二氧化碳监测与数据记录终端

> 项目持续开发中。当前重点是稳定完成传感器采集、数据缓冲、Flash 记录和趋势查看，不在 README 中提前声明尚未验证的功能。

本项目使用 STM32F103C8T6 读取 SCD40 的 CO2、温度和湿度数据，通过内存缓冲与均值处理降低短时波动。W25Q64 驱动和串口输出已经完成基础验证，长周期记录与 VOFA+ 趋势回放仍在集成。

## 当前已完成

- SCD40 I2C 驱动：周期测量、CRC 校验及 CO2/温湿度换算；
- 10 组数据缓冲与均值处理，原始数据先保留在 RAM 中，再输出平均结果；
- W25Q64 SPI 驱动：初始化、绝对地址读写、相对地址追加读写和整片擦除接口；
- 以 `HAL_GetTick()` 组织约 3 s 的传感器采样任务；
- OLED 实时显示与串口输出基础链路；
- Driver / Manager / Application 分层，传感器和存储模块通过接口向上层提供数据。

## 数据链路

```text
SCD40 -> I2C 驱动 -> 10 组 RAM 缓冲 -> 均值处理 -> OLED / 串口
                                        |
                                        +-> W25Q64 长周期记录（集成中）
```
